# Veilgram

Research-stage, unofficial Telegram client for iOS. A clean official Telegram-iOS simulator baseline compiled successfully in [BUILD-0](https://github.com/Jigros/Veilgram-Build/actions/runs/36378626863). No Veilgram build or features are available yet.

Development starts with a verified Telegram-iOS upstream baseline. See the research branch and its parity and build documents before treating any feature as supported.
