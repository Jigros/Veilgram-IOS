# Third-party and licensing record

No implementation code from Nicegram, Swiftgram, AyuGram, exteraGram, Ghostgram or iOS tweaks has been copied into Veilgram.

## Imported foundation

Telegram-iOS 12.9.2 at exact commit `6ad963e5b62d354da79040f388ae2b9132fb17b8` is imported with its Git history, submodule references, notices and file-level license material preserved. The official upstream README is retained at `docs/UPSTREAM_BUILD.md`.

Telegram-iOS contains components under multiple licenses and notice files. This repository does not replace those terms with a single blanket license. Review the license and provenance of each file or component before modifying, copying or redistributing it, and publish corresponding source when required.

## Reference-only projects

Public clients such as Nicegram and Swiftgram demonstrate the full-source fork model, but their code, private submodules, branding and credentials are not dependencies of Veilgram. AyuGram, exteraGram, Ghostgram and tweak projects remain research references only until exact commits, file provenance and license compatibility are reviewed.

Attribution is not a substitute for permission or a compatible license.
